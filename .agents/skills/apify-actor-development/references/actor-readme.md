# Actor README guidelines

The README is the Actor's landing page on Apify Store — critical for SEO, onboarding, and support.

## Required structure

1. **What does [Actor name] do?** — 1-2 sentences, include target site link, bold key terms
2. **Why use [Actor name]?** — Business use cases, features, platform advantages
3. **What data can [Actor name] extract?** — Table of key output fields
4. **How to scrape [target site]** — Numbered step-by-step tutorial
5. **How much will it cost?** — Pricing expectations
6. **Input** — Reference the input tab, explain complex fields
7. **Output** — Show simplified JSON example, mention download formats
8. **FAQ, Disclaimers, and Support** — Legal disclaimer, troubleshooting tips

## Key rules

- Always write the README — do not skip this step
- The first 25% is what most visitors read — put key info first
- Target at least 300 words
- Use H2 for main sections (H1 is the Actor name automatically)
