# Output schema reference

## Structure

```json
{
    "actorOutputSchemaVersion": 1,
    "title": "<OUTPUT-SCHEMA-TITLE>",
    "properties": {}
}
```

## Template variables

- `links.publicRunUrl` - Public run URL
- `links.consoleRunUrl` - Console run URL
- `links.apiDefaultDatasetUrl` - Default dataset API URL
- `links.apiDefaultKeyValueStoreUrl` - Default key-value store API URL
- `links.containerRunUrl` - Container web server URL
- `run.defaultDatasetId` - ID of the default dataset
- `run.defaultKeyValueStoreId` - ID of the default key-value store
